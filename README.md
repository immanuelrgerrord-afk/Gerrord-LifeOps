# LifeOps

A premium offline-first Personal Finance Progressive Web App (PWA).

## Features

- Offline-first
- IndexedDB storage
- Income & Expense Tracking
- Loan Management
- Credit Card EMI Tracking
- Home Loan Prepayment Simulator
- Goals
- Monthly PDF Reports
- JSON Backup & Restore
- Dark / Light Theme
- Installable PWA

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Router
- IndexedDB
- Tailwind CSS
